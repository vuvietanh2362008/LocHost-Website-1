# LocHost Website — Figma to HTML/CSS/JS

Responsive educational website based on the visible layout of the LocHost Figma screenshot.

## Run locally
Open `index.html` in a browser or use VS Code Live Server. No build or npm required.

## Pages
- `index.html`: homepage, search and stays section
- `property.html?id=1`: property details and demo booking
- `signin.html`: demo sign in
- `signup.html`: demo sign up

## GitHub Pages deployment
1. Create a public GitHub repository (e.g. `lochost-website`).
2. Upload **the files inside this folder** to the repository root and commit.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. After deployment, visit `https://YOUR_USERNAME.github.io/lochost-website/`.

## Notes
- Forms are demos; there is no authentication, payment, or booking backend.
- Property photos load from Unsplash and need an internet connection.
- The provided screenshot is a zoomed-out Figma overview, so this is an approximation, not a pixel-perfect export.
